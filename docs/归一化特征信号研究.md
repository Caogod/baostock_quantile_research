# 归一化特征信号研究

**思路**：把价格归一化成**尺度无关的比值**再研究信号。之前的特征混入了绝对值（成交额、价格水平），会因市值/股价差异产生**样本选择偏差**——上一轮报告里「换手率、成交额偏高」就是这类伪信号。

**样本**：`data_library/combined_daily.parquet`，2025-11-12 ~ 2026-10-09，可交易池（非科创/非ST/上市满180天且前向可算）**147984** 个股票日

**前向口径**：T 日观测 → T+1 开盘买入 → T+5 收盘卖出（持有 5 个交易日），扣双边 0.1% 手续费

## 二、全库分档筛选（主力，无偏）

对每个归一化特征在全库做 5 档分位。**「收益价差」= 最高档均收益 − 最低档均收益**，是最直接的信号强度度量；**「趋势分」= 相邻档均收益差值的符号和**（+4 严格递增、−4 严格递减、0 为混合，说明不是单调关系）。

**「Q1上界」/「Q5下界」给出最低档的上界与最高档的下界**——若某特征只有 Q1 明显更好（趋势分接近 0），说明它是**阈值型**信号，这时应该直接拿 Q1上界当门槛，而不是当单调因子用。

## 五、结论

- **信号最强的归一化特征是「MA5/MA60」**：最低档 → 最高档的均收益从 0.376% 变到 -0.582%（价差 -0.957pp，胜率价差 -8.55pp，Spearman -0.064）。
- **「只有最低档有效」的阈值型特征**（Q1 比其余档平均高出 ≥0.3pp，其余档之间并不继续单调变化）：MA20 五日斜率(%) ≤ -2.138（Q1 +0.425% vs 其余档 -0.182%）；close/MA60 ≤ 0.8995（Q1 +0.416% vs 其余档 -0.636%）；MA5/MA60 ≤ 0.9058（Q1 +0.376% vs 其余档 -0.626%）。这类条件应直接当**门槛**用，不要当线性因子。
- **数值越低越好的特征**：MA5/MA60(-0.957pp)、close/MA60(-0.954pp)、MA20 五日斜率(%)(-0.368pp)、close/近5日最高价(-0.184pp)。这说明样本期内的普适信号是**超跌/均值回复**，而不是动量——这与 `b1_oversold`（超跌型）在本项目里表现最好相互印证。
- **数值越高越好的特征**：close/MA20(+0.300pp)、近5日振幅(高/低-1, %)(+0.270pp)、近5日涨幅(%)(+0.199pp)、近5日平均换手率(%)(+0.158pp)。注意这些价差都很小（<0.3pp），基本不具备单独使用价值。
- **基本无信号**（价差 <0.15pp）：量比(量/5日均量)、当日换手率(%)、换手率 5日/20日、近20日平均换手率(%)、close/近5日最低价、close/MA5。特别是**换手率系列（当日/5日/20日/扩张比）价差都极小**，说明上一轮报告里「起涨前夜换手率偏高」确实是**样本选择偏差**（起涨股本身更活跃），不是可交易信号——换成归一化口径后这一点被证实。

- **起涨前夜画像（归一化口径）**：close/近5日最高价(z=-1.31)、近20日平均换手率(%)(z=+1.02)、近5日振幅(高/低-1, %)(z=+0.98)、近5日平均换手率(%)(z=+0.94)。
  其中 `close/近5日最高价` z 最负，含义是**起涨前夜收盘价明显低于近 5 日高点**（均值 0.906 vs 全库 0.957，低约 5pp），即典型的回调/阴线位置；而 `成交额`（绝对量）z 同样突出，属于偏差对照。

> ⚠️ **两条分析线方向不同，不要混用**：全库分档筛选（第二节）是**普适的前向收益规律**，结论是「超跌更好」；而起涨前夜画像（第三节）来自 `consecutive_up5` 的锚点，该锚点集合**按构造就是一轮上涨之后**，所以它的画像是「已上涨途中的回调」，回答的是「这类上涨行情启动前长什么样」，两者是不同的问题，不能互相替代。

> 反复提醒：以上均为**候选假设**。分档价差没有考虑重叠样本、多重比较和交易成本之外的执行细节，不能直接等同于可交易 edge；任何要落地的条件都应在更长时间序列上做样本外检验。
