# 20 个经典量化策略梳理（低频视角）

> 面向 A 股日频/周频级别低频量化研究的经典策略梳理。每个策略包含：核心原理、信号逻辑、典型参数、适用场景与主要风险。文末附与本仓库现有策略的映射关系。

---

## 一、趋势跟踪类

### 1. 双均线交叉（MA Golden/Death Cross）
- **原理**：短期均线与长期均线的相对位置刻画趋势方向；金叉（短上穿长）看多，死叉看空。
- **信号**：`MA5 上穿 MA20 → 买入`；`MA5 下穿 MA20 → 卖出`。
- **典型参数**：5/20（短线）、20/60（波段）、50/200（长线"黄金交叉"）。
- **风险**：震荡市反复止损（"锯齿亏损"）；滞后于拐点。
- **改进**：加成交量确认、加趋势过滤器（如 ADX > 20 才交易）。
- **本仓库映射**：`strategies/ma_golden_cross.py`（均线金叉 + 放量）即此策略。

### 2. MACD 趋势跟踪
- **原理**：快慢 EMA 之差（DIF）及其平滑（DEA）刻画趋势动能；柱状线收缩预示动能衰减。
- **信号**：DIF 上穿 DEA（金叉）且零轴之上 → 多头；DIF/DEA 顶背离 → 减仓。
- **典型参数**：12/26/9。
- **风险**：与双均线同源的滞后性；背离可能长期不兑现。
- **改进**：零轴上方金叉才入场（顺大势做小势）。

### 3. 海龟交易法则（Donchian 通道突破）
- **原理**：价格突破 N 日最高价说明趋势启动，跟随突破入场；反向突破或 ATR 止损离场。
- **信号**：`收盘价 > 过去 20 日最高价 → 买入`；`收盘价 < 过去 10 日最低价 → 平仓`。
- **典型参数**：入场 20 日 / 出场 10 日；止损 2×ATR；仓位 ∝ 1/ATR（波动率倒数头寸）。
- **风险**：假突破多、胜率低（典型 35%~45%），靠盈亏比取胜；需要严格纪律。
- **要点**：这是"低胜率、高盈亏比"策略的教科书范例，回测评价应以期望值而非胜率为准。

### 4. ATR 通道 / 肯特纳（Keltner）突破
- **原理**：以均线为中轨、ATR 倍数为带宽构造通道，突破上轨视为波动率扩张 + 趋势启动。
- **信号**：`收盘价 > MA20 + 2×ATR20 → 买入`；回归中轨 → 卖出。
- **典型参数**：MA20、ATR20×2。
- **风险**：单边暴跌中的假突破；需配合大盘风控。

### 5. 均线粘合突破（Squeeze Breakout）
- **原理**：长短期均线收敛（粘合）代表多空平衡、波动率压缩；随后放量突破往往是一段行情的起点（"横有多长，竖有多高"）。
- **信号**：`MA5/MA10/MA20 彼此偏离 < 3% 且持续 N 日` + `收盘价突破前一日 MA5 达 5%` + `换手率放大` → 买入。
- **风险**：粘合后向下突破同样常见，方向判断依赖量能与大盘环境。
- **本仓库映射**：`strategies/ma_breakout.py`（均线粘合 ±3% + 破 MA5 达 5% + 换手 >10%）即此策略；`ma_breakout_shift.py` 为其延迟 5 日入场版本。

## 二、均值回归类

### 6. 布林带均值回归
- **原理**：价格在统计通道内围绕中轨波动，触及下轨后倾向于回归均值（适用于震荡市）。
- **信号**：`收盘价 < 布林下轨（20, 2σ）且 RSI < 30 → 买入`；回归中轨 → 卖出。
- **典型参数**：20 日、2 倍标准差。
- **风险**：趋势市中"接飞刀"——下轨不断下移；必须带止损。
- **改进**：只在长期趋势向上（如价格 > MA120）时做回归。

### 7. RSI 超买超卖反转
- **原理**：短期涨跌力度极端化后出现技术性修正。RSI < 30 超卖、> 70 超买。
- **信号**：`RSI14 < 30 后拐头向上 → 买入`；`RSI14 > 70 → 卖出`。
- **风险**：强趋势中超卖可以更超卖；单独使用胜率不稳定。
- **改进**：与趋势过滤（EMA200 上方才做多）、成交量配合。

### 8. 短期反转（1 个月反转因子）
- **原理**：A 股横截面显著的中短期反转效应——前期跌幅最大的股票组合未来 1~4 周倾向于跑赢（追跌杀涨的散户结构导致过度反应）。
- **信号**：每期（周频）买入过去 20 日跌幅最大（且非退市风险、流动性达标）的前 N 只，持有 1~2 周。
- **风险**：反转股常伴随利空（业绩雷、减持），需基本面负面清单过滤；纯反转在单边下跌市失效。
- **学术出处**：Jegadeesh (1990)、Lehmann (1990)；A 股实证效果强于美股。

### 9. 配对交易 / 统计套利（Pairs Trading）
- **原理**：寻找价差序列平稳（协整）的资产对（同行业、同 beta），价差偏离历史均值时做多低估、做空高估，回归后平仓。
- **信号**：`spread = log(P_A) − β·log(P_B)`，z-score > 2 → 做空价差；< −2 → 做多价差；|z| < 0.5 平仓。
- **风险**：协整关系破裂（结构性变化）；A 股融券受限，实务多用"只做多低估腿"的弱化版。
- **工具**：statsmodels `coint` 检验、Kalman 滤波动态 β。

### 10. 网格交易（Grid Trading）
- **原理**：在价格区间内等间距挂买卖单，跌买涨卖赚取震荡收益，本质是机械化的均值回归。
- **信号**：以中枢价 P0 为基准，每下跌 x% 买入一份，每上涨 x% 卖出一份。
- **典型参数**：网格间距 3%~8%，仓位分 10~20 份。
- **风险**：单边下跌击穿网格满仓套牢；单边上涨提前空仓踏空。需设定整体止损线与标的选择（宽基 ETF、不会退市的标的）。

## 三、动量与轮动类

### 11. 横截面动量（相对强度选股）
- **原理**：过去 3~12 个月涨幅居前的股票未来仍倾向于跑赢（动量效应）。注意 A 股动量弱于美股、且期限更短（1~3 个月），中期（6~12 个月）反而呈现反转。
- **信号**：每月末按过去 60 日涨幅排序，买入前 10%，等权或市值加权持有 1 个月。
- **风险**：动量崩溃——市场风格急转时强者瞬间转弱（如 2014 年末、2021 年初）。
- **改进**：用 12M-1M（剔除最近一月）规避短期反转干扰。

### 12. 时间序列动量（TSMOM）
- **原理**：不看横截面排名，看单一资产自身历史收益方向：过去 N 月为正则做多、为负则做空。Moskowitz & Ooi (2012) 在多资产上验证显著正收益。
- **信号**：`过去 12 月收益 > 0 → 做多`，否则空仓/做空；仓位按 1/σ 标准化。
- **典型应用**：商品、股指期货；A 股个股层面因无做空受限，多用"做多或空仓"两态。
- **风险**：与横截面动量相同的崩溃风险。

### 13. 双动量（Dual Momentum, Gary Antonacci）
- **原理**：结合绝对动量（时间序列）与相对动量（横截面），用资产自身 12 月收益与无风险收益比较决定是否入场，再在多资产间选最强。
- **信号**（经典股债版本）：
  1. 若 `标普500 过去12月收益 > 0`：在 `标普500 vs 全球股票` 中选过去 12 月收益更高者做多；
  2. 否则做多短期国债（避险空仓）。
- **风险**：换仓频率低（年频），但动量崩溃年份回撤仍可观。
- **价值**：低换手、规则简单、长期夏普较高，适合个人低频配置。

### 14. 行业轮动（Sector Rotation）
- **原理**：行业间相对强弱领先于基本面景气，跟踪动量/景气度做行业切换（美林时钟的思想内核）。
- **信号**：每月末对一级行业指数按过去 20/60 日动量打分，超配前 N 个、低配后 N 个。
- **风险**：行业切换摩擦大、信号噪声高；行业ETF流动性差异。
- **改进**：加入北向资金行业净流入、行业 PE 分位作为景气确认。

### 15. 二八轮动（大小盘风格轮动）
- **原理**：A 股大小盘风格（沪深300 vs 中证500/1000）强弱切换显著且有持续性，"二八"指二八行情切换。规则：比较两指数动量，全仓切到强者。
- **信号**：每日/每周比较 `沪深300` 与 `中证500` 过去 N 日涨幅，持有强者；两者都跌则空仓（或持债）。
- **典型参数**：N = 20~60 日，月频或周频调仓。
- **风险**：风格切换高频反复触发（"打脸"）；需设冷却期或确认阈值。
- **本仓库映射**：`build_data_library.py` 已支持 hs300/zz500/sz50 成分股，可作为二八轮动数据底座。

## 四、因子与选股类

### 16. 多因子选股（Fama-French / Barra 体系）
- **原理**：收益可分解为多个风格因子暴露——价值（PB/EV）、成长、质量（ROE/毛利率）、动量、规模、低波。用打分或回归综合选股。
- **信号**：每月末对全市场按多个因子 z-score 加权打分，买入综合得分前 N 只。
- **典型因子**：价值 EP/BP/SP/股息率；质量 ROE/ROIC/应计异常；动量；低波；规模。
- **风险**：因子拥挤与衰减（价值因子 2017 后长期失效）；需做因子衰减与拥挤度监控。
- **工具链**：Qlib Alpha158、alphalens 因子分析、pyfolio 组合归因。

### 17. 小市值策略（Size Effect）
- **原理**：Banz (1981) 小盘效应；A 股 2010–2016 年小市值超额收益极其显著（壳价值 + 流动性溢价），2017 后明显衰减但仍长期有效。
- **信号**：每月末买入市值最小（剔除 ST、退市风险、流动性极差）的前 50 只，等权持有。
- **风险**：容量极小（个人策略，机构进不去）；2017 注册制预期下大幅回撤；退市新规后尾部风险剧增。
- **要点**：典型"alpha 显著但容量有限"的策略，回测漂亮但实盘上限低。

### 18. 低波动率异象（Low Volatility Anomaly）
- **原理**：实证上低波动率股票长期风险调整后收益反而更高（与 CAPM 高风险高收益预期相悖），因杠杆约束与彩票偏好导致高波动被高估。
- **信号**：每月末按过去 60 日波动率排序，买入最低的 50 只，等权/最小方差加权。
- **风险**：牛市/成长行情中显著跑输（2020 核心资产年）；换手低但需长期忍耐。
- **改进**：与价值、质量因子叠加（"低波 + 高股息 + 低估值"红利低波组合）。

## 五、其他经典低频策略

### 19. 双低可转债轮动
- **原理**：可转债兼具债底保护与期权弹性，"双低"（低价格 + 低溢价率）兼顾安全与弹性，是 A 股个人低频量化的经典策略。
- **信号**：每日/每周按 `价格 + 100×转股溢价率` 排序，买入前 10~20 只，定期轮动。
- **典型阈值**：价格 < 115、溢价率 < 30%。
- **风险**：信用违约（搜特、蓝盾退市转债）；强赎条款触发被迫提前转股。
- **要点**：年化收益与回撤比长期优秀，但近年拥挤度上升、信用事件增加。

### 20. 日历效应策略（春节效应 / 月末效应）
- **原理**：A 股存在显著的日历异象——春节前后 5~10 个交易日大概率上涨（"春季躁动"），月初/月末资金面-driven 的收益率差异。这些是行为 + 制度驱动的低频规律。
- **信号**：
  - 春节效应：春节前 5 个交易日建仓，节后 5 个交易日平仓。
  - 月末效应：每月最后 1~3 个交易日 + 下月前 2 个交易日持有宽基。
- **风险**：样本量小（一年仅一两次春节）、规则过于简单易被资金抢跑；需配合趋势状态过滤。
- **价值**：作为辅助择时叠加在其他策略之上提升风险调整收益。
