**锚点**：策略逐日全量判定的**全部信号**（不施加回测冷却期，避免锚点被稀疏化）  
**前兆窗口**：信号日之前的 60 个交易日（offset = −60 … −1，−1 = 信号前一日）  
**前向结局**：T+1 开盘入场、持有 3/5/10 个交易日收盘卖出，扣除双边 0.1% 手续费  
**符号约定**：正文中的「区间累计涨幅」= 信号日收盘 / 该日收盘 − 1，即从该偏移日持有到信号日的收益，**正值表示上涨**。

## 八、结论与改进方向


### consecutive_up5

- **前兆形态**：信号日之前的价格路径（中位）——60 日前累计涨幅 44.7%、20 日前 31.8%、5 日前 27.2%、1 日前 5.2%（正值＝当时价格低于信号日价格）。
  - 属于**持续上行**形态：最低价出现在窗口起点附近（-59 日前，低于信号日 45.0%），此后单边上行；最近 5 日贡献 +27.2%，占整段 60 日涨幅的 61%。
- **最能区分盈亏的前兆特征**：20日乖离率(%)（盈利均值 18.62 vs 亏损均值 22.04，t = -2.94）。
- **可执行改进**：基准（全部锚点）5 日胜率 48.7%、均收益 0.72%；采用「仅保留最低 3 档」后为 53.8% / 2.16%（锚点数 396 → 238）。
- **月份波动极大**：最差 2026-09（胜率 14.3%、均收益 -10.19%），最好 2026-04（69.0%、4.76%）——说明收益高度依赖市场风格，而非稳定 alpha。

### trend_pullback_inflow

- **前兆形态**：信号日之前的价格路径（中位）——60 日前累计涨幅 2.9%、20 日前 11.9%、5 日前 2.9%、1 日前 -0.9%（正值＝当时价格低于信号日价格）。
  - 属于**先跌后涨（V 形）**形态：最低于信号日 11.9% 出现在 -20 日前，此后一路反弹——从最低点回升 12.9% 到信号前一日；信号日本身转为阴线回调（中位 -0.90%）。
- **最能区分盈亏的前兆特征**：20日乖离率(%)（盈利均值 9.06 vs 亏损均值 8.29，t = 2.93）。
- **可执行改进**：基准（全部锚点）5 日胜率 44.0%、均收益 -0.45%；采用「剔除最低分位（dist_ma20 最小 20%）」后为 46.2% / 0.03%（锚点数 1358 → 1086）。
- **月份波动极大**：最差 2026-08（胜率 25.9%、均收益 -2.70%），最好 2026-04（70.9%、5.02%）——说明收益高度依赖市场风格，而非稳定 alpha。

> 说明：以上结论均由本次样本（2025-11-12 ~ 2026-10-09，788 只）自动计算得出；样本期约 11 个月，且策略信号在月份间胜率波动极大，任何「改进方案」都需在更长样本上复验后再落地。
