## 二、🔴 最严重问题：信号日 = 入场日 且用收盘价入场（结构性高估）

**[事实]** `core/backtester.py`：
```python
sub = df.iloc[: i + 1]          # L83：sub 含信号日当日完整 OHLC
sig = strat.signal(sub)         # L85：信号在信号日收盘后才能算出
entry_date = dates[i]           # L91：入场日 = 信号日
entry_price = float(close.iloc[i])  # L92：入场价 = 信号日收盘价
```

所有策略 `signal(df)` 都用 `df.iloc[-1]`（信号日当日 close/turn/volume）判断。

**[判断]** 这意味着回测假设"在 T 日收盘那一刻，既完成信号判断、又以该收盘价成交"。实务上：
- 盘后选股最早只能 **T+1 开盘** 下单（settings 的 schedule 15:30 已是收盘后）；
- 即使 T 日尾盘集合竞价下单，也需要在收盘前预知收盘值——不可能。
- 因此回测把"T 日信号触发所需的当日涨幅"错误地计入了"买入后的收益"。

**[判断] 影响最严重的策略**：
- **ma_breakout**：条件2要求"收盘较前日MA5涨5%"才入选，又以当日收盘价入场——这5%涨幅直接成了"买入价"的一部分，回测收益=从已涨5%位置再持有5日。实盘T+1开盘会吃掉这5%的大部甚至全部。**ma_breakout 的回测收益系统性高估，可信度最低。**
- 这正是 `ma_breakout_shift5` 被设计出来作对照的根因（设计思路对），但 shift5 仍用收盘价入场（见下）。

**[事实] README §八已知限制**只标注了"累计收益独立复利高估"与"幸存者偏差"，**未标注此条更根本的高估来源**。

**改进建议（优先级 P0）**：
- 方案A（最小改动）：入场价改为 `open.iloc[i+1]`（次日开盘），`entry_date=dates[i+1]`，exit 同步后移1日。需处理持仓期末越界。
- 方案B（更现实）：T日收盘选股 → T+1 VWAP/开盘均价入场。
- 实盘口径（selector）本就是T+1，应让回测与实盘口径一致。

## 三、🟠 次要问题：Welch t 检验样本重叠（统计缺陷）

**[事实]** `strategies/quantile_volume.py`：
```python
base_vol   = volume.iloc[-self.window:]        # L125：60日，含当日
recent_vol = volume.iloc[-self.recent_days:]   # L126：10日，含当日，且是 base_vol 的子集
p = _welch_ttest_pvalue(recent_vol, base_vol)  # L127：两组有 10 日重叠
```

**[判断]** Welch t 检验前提是"两组独立样本"。此处 recent_vol（近10日）完全是 base_vol（近60日）的子集，样本重叠使协方差被低估、t 值偏大、**p 值系统性偏小（更易判定显著）**。即"近10日量能显著上升"的结论被夸大，触发数与胜率都被污染。

**改进建议（P1）**：基准期应剔除近期窗口与当日：
```python
base_vol   = volume.iloc[-self.window:-self.recent_days]  # 历史50日基准，不含近10日与当日
recent_vol = volume.iloc[-self.recent_days:]              # 近10日（可含当日，当日已知）
```
修正后需重跑回测，触发数大概率下降——这才是该策略真实表现。

## 四、🟡 模型时序泄漏（CV 口径错误）

**[事实]** `train_model.py` L75：`cross_val_score(model, X, y, cv=5)` —— sklearn 默认 `KFold` 随机分折。

**[判断]** 金融时序数据用随机 K 折，会把"未来样本"放进训练集预测"过去样本"，**严重高估模型准确率**。当前输出的"GBDT 5折准确率"数字不可直接采信。

**[事实]** 标签 `df["win"] = (df["return_pct"] > 0)`（净收益>0）。

**[判断]** 未扣基准。牛市里随机买入大概率>0，模型学到的可能是"牛市特征"而非"策略 alpha"。建议标签改为"相对沪深300同期超额收益>0"。

**[判断] 二次过滤的循环依赖风险**：win_model 用"回测历史交易"训练，再去过滤"未来选股"。需确保训练区间严格早于过滤区间，否则存在"用近期预测近期"的时序泄漏。

**改进建议（P1）**：
- CV 改 `TimeSeriesSplit(n_splits=5)`；
- 训练期与过滤期显式分离（如训练 2024，过滤 2026）；
- 标签改"超额收益>0"；
- 小样本下 GBDT 易过拟合，加 `subsample`/`min_samples_leaf`、监控训练vs验证差距。

### 共性问题（适用于全部 7 个策略）
1. **无止损**：信号触发即持有 N 日无条件卖出，无单笔止损/追踪止损。突破类策略假突破亏损会放大。
2. **无大盘风控**：不判断指数趋势，熊市照样满仓入场。建议加"沪深300<MA60 则空仓"过滤。
3. **无信号冷却期**：粘合/分位状态可连续多日维持，会连续触发重叠持仓，叠加"独立复利"口径进一步高估累计收益。
4. **无基准对比**：只有绝对胜率/涨幅，无 alpha。胜率55%但市场同期涨10%的5日持有，alpha 可能为负。
5. **score 量纲不统一**：均线偏离度与量比线性相加，仅用于排序可接受，但不可作"信号强度"定量解读。

## 九、PM 七问速答（针对 ma_breakout 家族，最成熟子集）

1. **什么被错误定价？** [判断] 假设"均线粘合压缩后的放量突破"预示趋势启动、后续5日有延续收益。市场未必错——A 股短线动量存在，但"粘合+突破"信号拥挤度高，超额可能已被快速均值回归吃掉。
2. **当前价格反映了什么？** [事实] 入场价已含5%当日涨幅。
3. **什么能证明论点？** [判断] 修正入场口径后，shift5 在 zz500 上 T+1 开盘入场的5日净收益仍显著为正且超沪深300。
4. **什么能推翻论点？** [判断] 修正后 alpha 转负、或胜率<50%且盈亏比<1。
5. **为什么是现在？** [判断] 当前回测口径未修正，结论时点过早。
6. **什么会改变仓位？** 加大盘风控后，熊市空仓即改变仓位。
7. **还缺什么证据？** [判断] 修正口径后的全样本回测 + 分层 + 风险调整收益 + 与无基准的 alpha 分离。
